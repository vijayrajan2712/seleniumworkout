# Gold / Oil / Forex Signal Terminal

A web app that streams a live, terminal-style feed of trading **signals** (not
auto-executed trades) for Gold (XAUUSD), WTI/Brent Crude Oil, and major forex
pairs. Signals are generated by combining several classic price-action
confluences with simulated macro news sentiment.

**This build ships with a simulated market data & news engine** so the whole
app runs end-to-end with zero API keys. See [Going live](#going-live) below
for wiring in real data.

## What it analyzes

For every 15-minute candle close, the signal engine evaluates:

- **PDH/PDL** — previous day high/low breakout & breakdown
- **PWH/PWL** — previous week high/low breakout & breakdown
- **PMH/PML** — previous month high/low breakout & breakdown
- **HH/LL market structure** (15m) — fractal swing-high/swing-low sequencing
  (higher-highs/higher-lows vs lower-highs/lower-lows) and break-of-structure
  (BOS) detection
- **CPR** (Central Pivot Range: Pivot / TC / BC) and the standard extended
  floor-pivot ladder **R1–R4 / S1–S4**, with breakout events fired on each
  rung crossed
- **Volume Profile / POC** — point-of-control and value-area position
- **News sentiment** — simulated macro headlines (Fed/ECB/BoE/BoJ/RBA policy,
  inflation prints, OPEC+, inventories, geopolitical risk, China demand,
  etc.) tagged per instrument with a rolling sentiment score

Each confluence contributes a weighted score; the combined score is
classified into `STRONG BUY / BUY / NEUTRAL / SELL / STRONG SELL` with a
confidence percentage and a plain-English reasoning trail — this is what
streams into the terminal panel.

**Signals only** — the app never places real trades. It's a decision-support
tool: you read the reasoning and act (or not) yourself.

## Architecture

```
trading-app/
  server/   Node.js + Express + WebSocket
    src/marketData/   simulated OHLCV candle generator & multi-timeframe store
    src/analysis/     levels, structure, CPR/pivots, volume profile, signal engine
    src/news/         simulated news generator with sentiment tagging
    src/index.js      REST API + WebSocket broadcast + live simulation loop
  client/   React (Vite) + lightweight-charts
    src/components/   Terminal, SymbolSelector, PriceChart, LevelsPanel, NewsFeed
    src/hooks/        useTradingFeed (WebSocket client)
```

The simulator advances 1 simulated 15-minute candle per real second per
symbol (with realistic drift/volatility regimes), so a full trading day
passes roughly every 96 seconds — you'll see PDH/PDL/CPR levels update and
signals evolve quickly without waiting for real markets to move.

## Running locally

**Server:**
```bash
cd trading-app/server
npm install
npm start        # listens on :4000
```

**Client:**
```bash
cd trading-app/client
npm install
npm run dev       # http://localhost:5173, proxies /api and /ws to :4000
```

Open `http://localhost:5173`. Pick a symbol on the left, watch the terminal
feed signals as breakouts/structure shifts/pivot crosses/news fire, and
toggle level overlays on the chart.

## Going live

To swap in real data later, only two modules need new implementations
behind the same interfaces — nothing else in the analysis/signal pipeline
changes:

1. **Market data** (`server/src/marketData/simulator.js`) — replace with a
   real OHLCV feed (e.g. Twelve Data, Alpha Vantage, OANDA, Finnhub). Feed
   real 15m candles into the same `CandleStore`.
2. **News** (`server/src/news/newsSimulator.js`) — replace with a real news
   API (NewsAPI, Finnhub News, GDELT) filtered to the same categories in
   `symbols.js`'s `NEWS_DRIVERS`, plus a sentiment model to score headlines.

Note: TradingView (even on a paid plan) does not provide a general-purpose
market data API for pulling candles into a third-party backend — its
Premium tier adds alerts/webhooks, not raw data access. A Pine Script alert
can `POST` to a webhook endpoint as an extra trigger source, but a real
price feed still needs to come from a dedicated data provider.
